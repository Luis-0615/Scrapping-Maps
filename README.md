# Scrapping-Maps

Repositório de ferramentas de pesquisa e coleta de informações de empresas e profissionais.

## Projetos

- **Maps:** projeto original do repositório (preservado).
- **LinkedIn:** [coletor de empresas, pessoas por cargo e leitura de URLs via MCP](linkedin/README.md).

O coletor do LinkedIn roda localmente com Chrome e uma sessão autenticada. O GitHub Actions executa testes offline. Não publique cookies, credenciais, exportações ou dados pessoais neste repositório.

> Respeite as condições de uso da plataforma e a privacidade dos titulares.
